# Predictor de sentencias SQL

Aplicación web que sugiere cómo continuar una sentencia SQL mientras escribes. Las sugerencias se basan en ejemplos incluidos en el proyecto; no se conecta a una base de datos.

## Funciones

- Sugiere la siguiente palabra de sentencias SQL.
- Permite aceptar una sugerencia haciendo clic o presionando `Tab`.
- Incluye ejemplos con las tablas `clientes` y `pedidos`.
- Reconoce sentencias `SELECT`, `INSERT`, `UPDATE` y `DELETE`.
- Está hecho con HTML, CSS y JavaScript, sin dependencias externas.

## Cómo usarlo

Abre el archivo `index.html` en un navegador y comienza a escribir una sentencia SQL.
